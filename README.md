## 🎨 Design & Features

- **Fully Responsive:** Optimized layouts tailored for all screen sizes, from mobile to desktop.

- **Continuous Scroll & Animations:** Smooth staggered entrance animations on scroll.

## 🛠️ Technology Stack

This portfolio is built entirely from scratch without heavy frameworks, relying strictly on clean and performant web technologies:
- **HTML5** for semantic, accessible structure.
- **CSS3** for layout (CSS Grid & Flexbox), complex animations, and responsive media queries.
- **Vanilla JavaScript** for scroll-reveal functionality, smooth navigation, and dynamic UI states.
